# BankGo Banking System

## Description

BankGo is a simple banking system written in C++ that allows users to create accounts, log in using an account number, and perform common banking operations.

## Features

* Create a new bank account with a unique 6-digit account number
* Deposit funds
* Withdraw funds with balance validation
* Transfer funds between accounts
* View current account balance
* View transaction history
* Generate account statements
* Exit the banking system

## Notes / Limitations

* Account data is stored only while the program is running
* Accounts are not saved after the program closes
* Maximum of 100 accounts can be stored during runtime
